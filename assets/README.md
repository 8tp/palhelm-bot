# Bot visual assets

`milestone-background-v1.png` is original AI-generated background art created
for Palhelm's milestone renderer on 2026-07-11. It deliberately contains no game
characters, logos, text, or copied Palworld assets. Runtime player portraits and
Pal icons are composited separately from the operator's Palhelm panel caches.

Generation prompt summary: an original colorful creature-survival fantasy island
at sunrise, deep navy/teal with warm gold light, calm central negative space,
subtle map contours, and circular portrait/icon framing zones. No characters,
creatures, people, logos, UI, text, watermark, or recognizable copyrighted game
assets.
